# Security Policy

HOMEiiOS is proprietary software. Do not disclose vulnerabilities publicly.

If you discover a security issue, contact the repository owner privately and
include only the minimum information necessary to reproduce the issue. Do not
access data that is not yours, disrupt a Home Assistant installation, publish a
proof of concept, or share credentials.

The repository must never contain Home Assistant access tokens, API keys,
`secrets.yaml`, `.storage`, database files, backups, certificates or private
keys.
